# 기획및분석

# 1. 정의

**알려드림(Alrdream)**은 사용자의 사업 아이템을 입력받아 AI 기반으로 기획 → 분석 → 설계까지 자동 생성해주는 워크스페이스형 서비스.

- AI 기반 사업 기획 자동화
- 워크스페이스 단위 관리
- 단계별 산출물 생성 (기획 / 분석 / 설계)

---

# 2. 워크스페이스 생성

## **“새 워크스페이스를 생성”을 누르면, 다음과 같은 선택지를 준다.**

- 생각해둔 사업 아이템이 있으신가요?
- 사업 아이템을 어떻게 해야할 지 고민되신가요?

## **“생각해둔 사업 아이템이 있으신가요?” 를 선택했다면**

정해진 설문에 따라서 객관식 및 주관식을 적게 한다. (설문 데이터도 보관)

AI가 이를 분석하여 정해진 형태에 맞게 기획안을 만들어 준다.

## **“사업 아이템을 어떻게 해야할 지 고민되신가요?” 를 선택했다면**

정해진 설문에 따라서 객관식 및 주관식을 적게 한다. (설문 데이터도 보관)

AI가 이를 분석하여 정해진 형태에 맞게 기획안을 만들어 준다.

---

# 3. 워크스페이스 상세

기존에 생성한 워크스페이스 상세 화면에 들어가면 메뉴에 “기획”, “분석”, “설계”, “설정” 들을 선택할 수 있게 한다.

---

# 4. 워크스페이스 수정 및 삭제

기존에 생성한 워크스페이스 상세 > 설정에서 만들어진 워크스페이스 수정 및 삭제를 할 수 있게 한다. 

---

# 5. 기획 수정

기존에 생성한 워크스페이스 상세 > 기획에서 “수정” 버튼을 누른다.

기존에 작성한 버전의 설문 데이터를 선택 후 불러와 내용을 수정하여 다시 AI가 이를 분석하여 정해진 형태에 맞게 기획안을 수정해준다.

이때, 각 버전별로 어떤 기획안을 작성했는지 기록을 남긴다.

---

# 6. 기획 삭제

기존에 생성한 워크스페이스 상세 > 기획에서 “삭제” 버튼을 누른다.

원하는 버전의 기획들을 다중 선택하여 삭제할 수 있게 한다.

---

# 7. 분석 생성

기존에 생성한 워크스페이스 상세 > 기획에서 원하는 기획안 버전 상세 화면 내에 “분석” 버튼을 눌러 분석한다.

AI가 정해진 기본적인 형태에 맞게 기본적인 분석 내용들을 만들어준다. 이때, 합법여부, 가용 리소스(물적, 인적) 및 경쟁 서비스 여부도 알려준다. 

---

# 8. 분석 수정

기존에 생성한 워크스페이스 상세 > 분석에서 생성된 분석의 내용을 수정할 수 있게 한다.

이때, 각 버전별로 어떤 분석안을 작성했는지 기록을 남긴다.

---

# 9. 분석 삭제

기존에 생성한 워크스페이스 상세 > 분석에서 “삭제” 버튼을 누른다.

원하는 버전의 기획들을 다중 선택하여 삭제할 수 있게 한다.

---

# 10. 설계 생성

기존에 생성한 워크스페이스 상세 > 분석에서 원하는 분석안 버전 상세 화면 내에 “설계” 버튼을 눌러 설계한다.

정해진 설문에 따라서 객관식 및 주관식을 적게 한다. (설문 데이터도 보관)

AI가 이를 분석하여 정해진 형태에 맞게 설계 문서를 만들어 준다.

---

# 11. 설계 수정

기존에 생성한 워크스페이스 상세 > 설계에서 “수정” 버튼을 누른다.

기존에 작성한 버전의 설문 데이터를 선택 후 불러와 내용을 수정하여 다시 AI가 이를 분석하여 정해진 형태에 맞게 설계 문서를 수정해준다.

이때, 각 버전별로 어떤 설계 문서를 작성했는지 기록을 남긴다.

# 12. 문서 추출 방식

문서는 AI 모델을 통해, PDF 확장자로 추출한다. (설문 → AI 분석 → 사업 아이템 솔루션 중심 PDF 생성)

## 12-1. 짚고 넘어 가야 할 것

- ❌ 그냥 정리만 해줌 → 여타 LLM 모델이랑 차이 없음
- ❌ 너무 추상적 → 실제로 못 씀
- ❌ 실행 단계 없음 → 가치 없음

## 12-2. 방향을 이렇게 바꿔야 함

👉 **“생각 정리 문서” ❌**

👉 **“실행 가능한 사업 설계서” ✅**

## 12-3. PDF 문서의 역할 정의 (핵심)

이 문서는 아래 역할을 해야 한다:

- **아이디어 명확화**
    - 내가 뭘 하려는지 정리됨
- **문제 검증**
    - 이게 진짜 의미 있는 문제인지
- **방향 제시**
    - 어떻게 만들지 감 잡힘
- **실행 가이드**
    - “그래서 뭐부터 해야 하지?” 라는 문제를 해결

## 12-4. PDF 구조

### 📌 아이디어 요약

- 한 줄 아이디어
- 해결하려는 문제
- 타겟 고객
- 핵심 가치

👉 투자자/지인에게 설명 가능한 수준

### 🔥 문제 정의

- 왜 중요한가
- 얼마나 자주 발생하는가

- 주요 사용자
- 사용자 특징
- 사용 시나리오

👉 단순 "직장인" → ❌

👉 "야근 많은 20~30대 직장인" → ✅

### 💡 솔루션 제안

- 서비스 개요
- 핵심 기능 3~5개
- 사용자 흐름 (간단)

👉 핵심사항

### 🧩 서비스 구조

예:

### 🆚 경쟁 / 대체 분석
